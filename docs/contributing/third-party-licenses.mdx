# Third-party licenses

bonsai-ninja is licensed under the MIT license. This document inventories the
licenses of its transitive dependencies for compliance and attribution.

## License audit summary

Current `Cargo.lock` / `cargo metadata --locked` graph: 327 packages
(47 workspace crates + 280 external packages).

The graph currently carries 25 distinct SPDX metadata expressions. The release
gate evaluates each expression as an SPDX choice rather than treating a
dual-licensed dependency as if every branch applied. Run the command under
[Reproducing the audit](#reproducing-the-audit) for the authoritative current
distribution; it is intentionally not duplicated as a hand-maintained count
table here.

Every locked expression offers an approved redistribution branch: permissive
MIT, MIT-0, Apache-2.0, ISC, BSD-2/3-Clause, 0BSD, Zlib, BSL-1.0, CC0-1.0,
Unicode-3.0, CDLA-Permissive-2.0, or Unlicense; the one accepted weak-copyleft
branch is file-level MPL-2.0. No GPL, AGPL, EUPL, SSPL, or LGPL-only
dependencies are accepted.

## Notes on specific licenses

### Apache-2.0

Apache-2.0 is permissive but requires preservation of the NOTICE file (when
present) and a notice of any modifications. We ship Apache-2.0 dependencies
unmodified; their copyright notices are preserved in their respective
crate sources.

### MPL-2.0

The single MPL-2.0 dependency (`option-ext`, pulled in transitively via
`tree-sitter-language-pack` → `dirs` → `dirs-sys`) is file-level copyleft.
MPL-2.0 explicitly permits including MPL-licensed files in a larger work
under a different license, provided the MPL files themselves remain under
MPL. bonsai-ninja does not modify `option-ext` source; users redistributing
bonsai with this dep retain the MPL terms only on the `option-ext` files.

### LGPL-2.1-or-later (in dual/triple license)

`r-efi` is `Apache-2.0 OR LGPL-2.1-or-later OR MIT`. We elect the MIT
branch.

### CDLA-Permissive-2.0

`webpki-roots` carries a permissive data license for the bundled root
certificate set. Compatible with MIT distribution.

## Reproducing the audit

```sh
cargo metadata --format-version 1 --locked > /tmp/bonsai-metadata.json
jq '.workspace_members | length' /tmp/bonsai-metadata.json
jq '[.packages[].license] | group_by(.) | map({license: .[0], count: length})' \
  /tmp/bonsai-metadata.json
```

`Cargo.lock` plus `cargo metadata --format-version 1 --locked` is the
authoritative resolved graph. License strings above normalize only equivalent
ordering/separator spellings such as `MIT OR Apache-2.0`,
`Apache-2.0 OR MIT`, and `MIT/Apache-2.0`. Re-run the audit when adding or
upgrading dependencies.

`python3 scripts/audit-dependency-licenses.py` is the release gate. It parses
each locked SPDX expression, requires at least one approved redistribution
branch, and fails closed on missing or previously unreviewed license ids. The
policy intentionally permits MPL-2.0 file-level weak copyleft and rejects
GPL/AGPL/SSPL/EUPL/LGPL-only expressions; dual-licensed dependencies pass only
when an approved branch is available.
