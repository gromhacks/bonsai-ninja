# Configuration

CLI flags take precedence over environment variables. Environment variables take precedence over built-in defaults. Rulepack lookup checks `--rules-dir`, then `BONSAI_RULES_DIR`, then workspace-local and cwd-relative `security-patterns/` locations.

## Config File Keys

bonsai-ninja does not require a project config file for normal scans. Workspace-local rule overlays use the file layout under `<workspace>/.bonsai/rules/`.

| Name | Type | Default | Description |
|---|---|---|---|
| `.bonsai/rules/` | directory | Absent | Optional workspace-local rule overlay. |
| `.bonsai/dataflow.v3.factstore` | generated file | Explicit prewarm or exact query commands | Persisted dataflow sidecar. Do not edit manually. |
| `.bonsai/value_flow.v3.factstore` | generated file | Exact query commands | Persisted value-flow sidecar. Do not edit manually. |
| `.bonsai/callgraph.v*.bin` | generated file | Query commands or `cache rebuild` | Persisted resolved-callgraph sidecar. Do not edit manually. |
| `.bonsai/idg.v*.factstore` | generated file | Query commands or `cache rebuild` | Persisted IDG sidecar. Do not edit manually. |
| `.bonsai/taint_graph.v2.factstore` | generated file | Security analysis commands | Persisted taint-graph sidecar. Do not edit manually. |
| `.bonsai/page-cache.v5/` | generated directory | Generated lazily | Rendered page cache for paginated CLI output. |
| `security-patterns/` | directory | Auto-discovered | Rulepack root when `--rules-dir` and `BONSAI_RULES_DIR` are not set. |

Sidecars are validated by source-content hashes, dependency hashes, and
pipeline-config fingerprints. Stale or mismatched sidecars are silently
ignored and rebuilt by the command that needs them. A normal `index` run
is structural-only; `index --prewarm-dataflow` explicitly rebuilds the
full-workspace dataflow sidecar. `index --watch` keeps a live workspace
open, polls for saved changes, reparses changed files in place, and can
combine with `--prewarm-dataflow` when save-time dataflow rebuilds are
intentional.

## Environment Variables

| Name | Type | Default | Description |
|---|---|---|---|
| `BONSAI_RULES_DIR` | path | Auto-discover | Rulepack directory. |
| `BONSAI_PARSE_TIMEOUT_MS` | integer milliseconds | `30000` | Per-file tree-sitter parse timeout. `0` disables the timeout guard. |
| `BONSAI_NO_DATAFLOW` | boolean-like | unset | Skip explicit dataflow prewarm and trace eager hydration. Query commands still compute required facts on demand. |
| `BONSAI_THEME` | string | `moss` | Terminal theme: `moss`, `earthy-dark`, `dracula`, or `retro-amber`. |
| `BONSAI_WORKSPACE_DIR` | path | Workspace root | Per-workspace state directory override. |
| `BONSAI_CONTEXT` | token budget | `32k` for text and JSON | Default paging/context budget. |
| `BONSAI_NO_CACHE` | boolean-like | unset | Disable in-process caches. |
| `BONSAI_RAYON_STACK_BYTES` | integer bytes | internal default | Rayon worker stack size override for very deep syntax trees. |
| `NO_COLOR` | boolean-like | unset | Disable color output. |
| `NO_PROGRESS` | boolean-like | unset | Disable progress output. |

## Precedence

| Setting | Highest precedence | Then | Default |
|---|---|---|---|
| Rulepack directory | `--rules-dir` | `BONSAI_RULES_DIR`, workspace/cwd discovery | None |
| Parse timeout | `--parse-timeout` | `BONSAI_PARSE_TIMEOUT_MS` | 30000 ms |
| Theme | `--theme` | `BONSAI_THEME` | `moss` |
| Context budget | `--context` | `BONSAI_CONTEXT` | 32k |
| Cache behavior | `--no-cache` | `BONSAI_NO_CACHE` | enabled |
