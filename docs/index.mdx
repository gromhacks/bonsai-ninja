# bonsai-ninja Documentation

bonsai-ninja indexes source code, resolves cross-file call paths, and runs
rulepack-driven security analysis across 20 parser adapters. Every supported
language uses the compiler-owned source/sink/sanitizer taint architecture.
These docs are plain MDX: readable on GitHub and enhanced by Mintlify where
supported.

The analyzer is a content-addressed compiler: Tree-sitter adapters publish
immutable per-file typed objects, the linker and one-pass IDG compiler consume
one atomic generation, and all query/security/export modes share those facts.
