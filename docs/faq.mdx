# FAQ

<AccordionGroup>

<Accordion title="Does bonsai-ninja hardcode language syntax or API names?">

No. Each language adapter owns its Tree-sitter grammar and lowers source
syntax into typed declarations, imports, flow events, places, types, modules,
receivers, constructors, and capability facts. Shared analysis consumes that
IR and rulepack-declared API semantics. A language-specific syntax fix belongs
in its adapter, not in a shared union of token or method names.

</Accordion>

<Accordion title="Does semantic prewarm parse every file repeatedly?">

No. It first publishes an atomic generation of content-addressed per-file
compiler objects containing typed adapter IR and diagnostics. Callgraph,
retrieval, linkage, IDG, security, inspect, and export stream those objects.
The persisted IDG path lowers transfer facts once and replays a compact typed
stitch spool; it does not run a second AST/transfer pass. Changed objects are
recompiled, while exact unchanged payloads are reused. The workspace linker
retains compact headers and stable symbols; exact bodies are streamed and
released in memory-aware batches instead of all remaining resident beside the
graph.

</Accordion>

<Accordion title="Is taint analysis capped or implemented as BFS?">

No. Production taint reachability is a sparse monotone closure over numeric
IDG edges and runs until the reachable fixed point is exhausted. It has no
name-search BFS, hidden call-depth limit, iteration budget, or result cap.
Paging, context budgets, and diagnostic path previews can limit rendered
output; they report more pages or explicit truncation and never change the
semantic result.

</Accordion>

<Accordion title="Why did a sanitizer not remove the finding?">

Sanitizers are evidence, not propagation blockers. The finding remains visible with `status` set from the sanitizer context so reviewers can decide whether the sanitizer is sufficient.

</Accordion>

<Accordion title="Why are there inferred entry-point findings?">

You passed `--inferred-sources`. That mode seeds synthetic sources at entry-point parameters for audit coverage. Omit the flag to use only real source rules.

</Accordion>

<Accordion title="How do I make output smaller?">

Use `--compact` on commands that support it, reduce `--context`, add `--severity`, `--tag`, `--source`, or `--sink`, and page with `--page next`. Security flow reports expand source bodies by default and add pages when the active context budget is full.

</Accordion>

<Accordion title="How do I get machine-readable output?">

Use `--format json --all` for native JSON. SARIF is emitted by `security taint-analysis --format sarif`; `security source-analysis` is source-flow mapping and should use JSON.

</Accordion>

<Accordion title="Why does rule validation reject my YAML?">

The rule loader denies unknown fields and validates constraints before scanning. Check field names, rule kind directory, match examples, and whether `arg_tainted` uses a positional index for languages without keyword-argument facts.

</Accordion>

<Accordion title="Why is a flow marked incomplete?">

The parser or adapter could not produce a required fact, the resolver could
not prove a semantic target, or the call had ambiguous semantic candidates.
Preview-only output can also report its own explicit truncation. Public
analysis does not widen those cases into guessed flows; use `diagnostics`,
`dump-ast`, `dump-resolve`, `dump-edges`, and `dump-taint` to inspect the
missing fact.

</Accordion>

<Accordion title="How do I clear stale cache data?">

Run `bonsai-ninja cache clear ./src --dataflow-only` to clear the dataflow sidecar, or `bonsai-ninja cache clear ./src` to remove the workspace's external analysis cache. `cache stats ./src` prints its exact path.

</Accordion>

<Accordion title="How do I keep results current while editing?">

Run `bonsai-ninja index ./src --watch`. It polls saved file changes, reparses changed files in place, tombstones deleted files, and prints fresh stats without forcing a whole-workspace semantic prewarm. Use `index ./src --semantic` for an explicit sidecar warm-up job. SDK `Project` facades use the same refresh path before commands run.

</Accordion>

</AccordionGroup>
